# Routing 唯一动作与外部条件注入

更新：2026-11-15。用户明确的模型边界是：**routing 是唯一 action；map、任务、指定车辆及其他已知外部事件属于条件输入。** 这取代了此前让世界模型学习派发匹配的方案。

**当前结论：不能扩大到正式训练。** 旧自动扩训脚本已禁用；上次进程在完成缓存前中断，没有实际开始训练。多步执行目标已加入诊断入口，但可扩展的正式训练方法和长期效果尚未通过验证。见[当前准入结论](../../runs/executed_routing_v1/readiness.json)。

## 实现边界

当前入口为 `conditioned_world_model_executed_routing_v1`。保留执行图记忆、直接加速度、资源事件学习及现有硬约束；不包含 `dispatch_skip`，任务事件不进入训练和推演候选，损失不包含派发匹配。

- 静态 map 初始化提供，routing 仍使用 `route_commit` 动作。
- 任务到达使用 `task_arrival`；任务—车辆绑定使用 `task_binding`，载荷只允许 `task_id` 和 `oht_id`，按输入时间生效。
- 空闲车辆接收绑定后开始任务；忙车保留绑定并等待任务槽。不能为满足输入而提前结束当前任务，也不复制真实开始时间。
- 到达、服务、任务完成、资源占用及运动状态继续随推演演化。执行后的实际状态变化继续更新记忆。
- 动态条件按时间边界揭示。当前接口不向模型提前暴露未来车辆绑定；提前已知计划需要真实的确认时间协议。

原生归档把派发决策记录在 `oracle_endogenous_events`。当前适配器**显式改变评估条件**：仅将从 CREATED 发出的分配／预分配决策转换为外部绑定；删除 `status_after`、`start_time`、`end_time` 等结果字段。不导入完成、服务、资源授权和预分配自动提升事件。这个协议衡量“给定绑定和 routing 的动力学”，不能证明模型能自行派发，也不能证明绑定在锚点就已知。

## 训练和评估

数据使用 `data --external-task-bindings --execution-profile learned_hard_only_v1`。局部真实序列预训练选择 `--architecture conditioned_world_model_executed_routing_v1 --factual-pretrain-only`，不提供此显式范围会报错，避免把它当成自由想象训练。旧派发缓存不能用于新模型。检查点保存 `routing_only_external_task_bindings_v1` 条件契约，加载时严格核验。

先检查注入顺序、忙车等待、身份一致性及无未来结果注入，再扩大独立种子、锚点和物理训练时长。训练依然是真实序列监督与执行记忆反馈，硬执行器没有多步反向传播；不能把加长训练窗口描述成完整的自由想象训练。

任务配对审计现在衡量输入绑定是否被正确执行，不再代表派发预测准确率。长期性能应看 10/30/60 秒位置与速度误差、运动召回、资源关系、任务完成与持续停滞，同时报告未执行的绑定和 routing 拒绝。

实验、验证和扩训状态见 [当前实验目录](../../runs/executed_routing_v1/)。旧 [自主派发实验](executed_graph_and_dispatch_contract.md) 保留作历史记录，其 0/126 不能充当新条件协议的动力学结论。

## 执行分布差距与关键切换修正

执行记忆已提取到独立公共模块；当前 routing 模型不再通过历史派发类继承记忆。旧派发模型仅保留检查点兼容入口。旧派发缓存已删除，保留原始数据、权重、报告和哈希清单。

新增 `closed_loop_objective`：从观察起点连续执行自身预测的资源事件和运动，只注入给定 routing、任务与绑定，真实目标仅在各检查时刻用于计分，不写回状态或记忆。速度、位置、资源关系、模式和当前任务均进入轨迹误差，所有车辆都计分。停车、资源切换、任务切换、服务区间不再被排除在这个多步目标之外。原局部加速度筛选保留：不能用瞬时硬停车的执行差分冒充可实现的连续控制标签。

新增 `train_closed_loop` 仅用于快速方向差分诊断：在实际执行器上扰动运动与资源头参数，比较两条完整执行轨迹的误差，再尝试一次参数更新。它确实跨越不可微硬执行器评分，但方差和成本限制尚未解决，**不是推荐的正式全模型优化算法**，也没有将原轨迹下一步当成偏离状态的 oracle 标签。

2 秒、train seed 0 / validation seed 50 的诊断结果：

- 自由推演速度 MSE 0.17293；每半秒从真实状态重新初始化的对照为 0.03579，相差约 4.8 倍。该对照同时重置物理状态和记忆，不能单独归因为 teacher forcing。
- 多步更新使训练轨迹综合误差 0.43466 → 0.41614，但独立验证误差 0.43044 → 0.43763，资源集合误差 0.27129 → 0.28158。
- 训练片段所有 1200 个车辆时刻参与计分，其中包含 42 次停车、29 次启动、107 项资源关系变化和 159 个服务车辆时刻。
- 这是一条轨迹、一个随机事件种子的短诊断，不是统计显著性结论；但它没有提供放行正式训练所需的长期改善证据。候选没有晋升。

来源：[诊断报告](../../runs/executed_routing_v1/closed_loop_diagnostic/report.json)。当前回归检查为 162 项模块测试和 23 项安全／兼容性测试。下一步应解决资源事件与运动在自身轨迹上的联合学习，并在相同输入协议的独立锚点完成成对 60 秒验证；不恢复原来的局部目标扩训方案。
